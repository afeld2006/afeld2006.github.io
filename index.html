2026 · HKUST research internship Python · scikit-learn R² ≈ 0.61

Predicting how annoying aircraft noise sounds

An ML pipeline that predicts perceived annoyance from aircraft-noise spectrograms, trained on ratings from a 55-participant listening study. A spectral-centroid baseline reaches RMSE ≈ 0.35. A Dynamic Mode Decomposition written from scratch did not beat it under leakage-free benchmarking, a negative result I documented.
2026 · LMPS research project Neural operators · MIFNO · HEMEWS-3D

A neural surrogate for 3D earthquake shaking

Full 3D wave simulations are too slow to run for every scenario. I trained a Multiple-Input Fourier Neural Operator on the HEMEWS-3D dataset to predict ground shaking from the subsurface geology and the earthquake source together, then tested whether it holds up on geologies it never saw in training.
2026 · EDF battery systems project Equivalent circuit · Extended Kalman filter

Real-time state of charge for an EV battery

A vehicle mechanics model drives a second-order Thévenin model of a lithium-ion cell, with RC parameters extracted from pulse-response data. An Extended Kalman Filter then estimates the pack's state of charge in real time.
2025 · Robotics bootcamp Python · Raspberry Pi

Autonomous line-following robot

A Raspberry Pi robot that follows a track with PID control, and combines several sensors to navigate smoothly, detect slopes and trigger its safety functions.

Research & experience

Jun – Aug 2026

HKUST Hong Kong SAR

Research Intern, Machine Learning · Dept. of Mechanical & Aerospace Engineering

Built an ML pipeline in Python and scikit-learn that predicts the perceived annoyance of aircraft-noise spectrograms, using ratings from a 55-participant listening study. A spectral-centroid baseline reached RMSE ≈ 0.35 and R² ≈ 0.61 (5-fold cross-validation, 20 % holdout).

Implemented Dynamic Mode Decomposition from scratch (SVD-based, verified on synthetic signals). Leakage-free benchmarking showed its temporal features did not beat the spectral baseline (RMSE 0.42), and I documented this negative result.

Feb – Jun 2026

LMPS Saclay, France

Research project · Laboratoire de Mécanique Paris-Saclay

Worked on a fast surrogate model for realistic 3D earthquake simulation, able to show how changes in geology or fault motion affect ground shaking without running the full physics simulation.

Trained a Multiple-Input Fourier Neural Operator (MIFNO) on the HEMEWS-3D dataset, with both subsurface properties and earthquake source parameters as inputs, and tested how well it generalises to unseen geologies.
